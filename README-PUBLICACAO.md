# Pacote de publicação — Landing Page UniqTrack

Este é um site estático: não exige Node.js, Python, banco de dados ou processo de build.

## Como publicar

1. Envie **todo o conteúdo desta pasta**, mantendo a estrutura de diretórios `assets/`.
2. Configure esta pasta como raiz do site (document root) no serviço de hospedagem.
3. O arquivo inicial é `index.html`.
4. Publique em HTTPS e valide a versão mobile e desktop.

## Verificações finais

- Testar os botões de chamada para ação: todos levam ao formulário da própria página.
- Preencher o formulário e confirmar a abertura do WhatsApp com a mensagem preenchida.
- Confirmar o número de destino: `+55 48 99901-1701`.
- Conferir se imagens, fontes e o ícone da aba foram carregados corretamente.

## Comportamento do formulário

O formulário **não armazena os contatos**. Após a validação, ele apenas abre uma conversa no WhatsApp com os dados e módulos selecionados.

## Conteúdo sujeito à validação de publicação

Os logos, nomes de marcas e os resultados exibidos foram fornecidos para esta landing page. Antes da publicação, a responsável deve confirmar as autorizações de uso comercial e a adequação das informações.
