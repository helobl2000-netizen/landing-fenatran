# Landing page UniqTrack — FENATRAN

Versão estática e mobile-first, sem backend nem dependências de build.

## Visualização local

No PowerShell, dentro desta pasta, execute:

```powershell
python -m http.server 8080
```

Abra `http://localhost:8080` no navegador. O formulário valida campos obrigatórios e abre o WhatsApp com a mensagem preenchida; não armazena leads.
